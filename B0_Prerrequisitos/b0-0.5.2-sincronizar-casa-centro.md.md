## ⌨️ Comandos y pasos importantes

- `git pull` — descarga y fusiona en el equipo local los últimos cambios subidos a GitHub antes de empezar a trabajar.
- `git add .` — añade los archivos modificados o nuevos al área de preparación (staging area).
- `git commit -m "mensaje"` — empaqueta los cambios preparados añadiendo un mensaje descriptivo de lo realizado.
- `git push` — sube los commits locales al repositorio remoto en GitHub para que estén accesibles desde otros equipos.

## 🤔 Respuestas a las preguntas

1. **¿Por qué NO se mete la bóveda en OneDrive si usamos Git?**
   Porque OneDrive y Git son dos sincronizadores que compiten por los mismos archivos. OneDrive intenta sincronizar la carpeta interna `.git` (corrompiéndola) y genera archivos de "copias en conflicto" (como `-MiPC.md`), anulando el funcionamiento de Git.
2. **Escribe el ciclo diario de tres pasos.**
   3. Al llegar al ordenador: `git pull` (descargar lo último).
   4. Durante el día: Trabajar y editar en Obsidian.
   5. Antes de irse: `git add`, `git commit` y `git push` (guardar y subir).
6. **¿Qué problema puede aparecer si olvidas el pull al empezar?**
   Puede producirse un conflicto de versiones (`CONFLICT`) si se ha modificado el mismo archivo en dos sitios distintos sin estar sincronizados previamente.
